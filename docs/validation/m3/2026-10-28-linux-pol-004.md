## Not covered by this record
- **Nothing calls the Guard.** No sender, Provider or agent path uses it yet. The confined agent's own network is open (ADR-0057 is writes only), so this does not stop an agent from reaching a URL. It is the decision and the connection check a future sender or gateway uses.
- The allowlist has no configuration source (Organization config is not wired) and "allowlisted" is therefore a field a caller sets.
- A denied or consented egress is not recorded as an Event or in the audit log.
- Redirects: the Guard returns the redirect; a caller must ask Policy for the new URL. No caller does yet.
- IANA ranges were written from memory of the registries, not checked against the registry text. The list errs toward refusing (NAT64, 6to4, Teredo are refused).
- HTTP/2, TLS certificate checks and SNI are the standard library's and are not tested here. DNS at the OS level (resolver search domains, `/etc/hosts`) is the system resolver's.
