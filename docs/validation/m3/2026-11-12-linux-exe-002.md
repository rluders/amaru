## Architecture and limitations

Architecture review: **sound**. Changes add test helpers and evidence around the existing store and Worker ports; no production APIs, schemas, dependencies or infrastructure are added. Domain code remains unchanged. Simulated restarts alone could not prove survival of process termination, which is why the PostgreSQL child-process suite is included. Test children and the parent use pipe barriers and bounded waits; the parent kills and reaps children before reading their output.

The process tests kill a coordinator test binary, not a complete Platform executable. PostgreSQL stays alive; server crashes, power-loss durability, a complete real-provider workflow and general retry-budget accounting were not validated by this change. macOS and Windows were not run natively. They are best effort for all remaining M3 work and exit under the [owner's 2026-11-12 scope decision](../../engineering/validation.md#scope-decision-product-owner-2026-11-12); no native pass is claimed. M4 requirements and confinement/security controls are unchanged.

Review and designated-base integration remain required before #129 closes; parent #15 remains open for #145, #157 and #158 and its integrated acceptance. No new architecture decision is requested.
