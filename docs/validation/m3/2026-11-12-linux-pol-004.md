## Results

**Integration-tested:** the shared coordinator suite uses the existing remotejob Provider helper, the consented Sender, stored execution identity/definition, actual loopback HTTP and both fake and PostgreSQL stores. A new Coordinator reads the stored Grant state. Missing or wrong-URL consent, revoked or expired Grants, expired leases, wrong fencing tokens, cancelled Executions, deny rules, missing trust and a failed decision-log commit send no request. The permitted endpoint receives one request, after its authorization Event is committed. Events and errors do not repeat the query token or request body. Trust standing is faked; this is not independent real validation of Project trust.

**Unit-tested and integration-tested:** Sender/Guard tests use a fake resolver/dialer and loopback server to cover public/private/loopback classification, explicit allowlisting, mixed DNS answers, metadata refusal even when allowlisted, actual use of the vetted IP, changed DNS between requests, no redirect following, no environment proxy/connection reuse, consent before DNS/body reads, URL credentials/Host override refusal, and safe transport errors through the download helper. Public-address dial tests substitute a loopback receiver after asserting the vetted IP; no public endpoint is contacted.

**Architecture review: sound within the accepted Policy/Grant model.** Domain code stays pure; network I/O stays in the egress adapter; the coordinator loads authoritative state through existing ports and commits Events before the side effect. No dependencies, infrastructure type, public API contract or migration is added. Using Guard alone is smaller but does not check consent. A denied or unavailable authorization fails closed. HTTP delivery remains a non-transactional side effect: a committed authorization is not proof of delivery, and later revocation cannot recall bytes.

**Not validated:** native macOS/Windows, real Providers, arbitrary child networking, a production composition/configuration-file loader, remote authentication and crash/power-loss during HTTP delivery. The low-level remotejob defaults retain their behavior; production integration must inject the Sender for requests and downloads. URL Approval creation is not implemented; this path uses covering Grants and refuses `require_approval`. The full PostgreSQL suite was not rerun for this scoped change; the new PostgreSQL consent suite and full `make check` were run. See [egress consent](../../engineering/egress-consent.md) for configuration and limits.
