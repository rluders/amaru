## Findings from this run
- The macOS PostgreSQL distribution is **263 MB installed, 2.3 times the Linux one** (115 MB); compressed the bundle is 94.6 MB. NFR-34's budget (≤ 120 MB installer increment, read as the compressed download, see the report) leaves about 25 MB for the Platform binary; the spike binary alone is 30 MB. **The budget is at risk on macOS** and the bundle was not trimmed. Requires a decision or a trimming task; not decided here.
- The Unix-domain socket path must stay under 104 bytes on macOS; with a long state path PostgreSQL refused to start, now handled by [`pgsup`](../../../spikes/wp-m1-02/internal/pgsup/pgsup.go) (see report).

Earlier attempts of the same workflow (runs before [run 40374670955](https://github.com/rluders/amaru/actions/runs/40374670955)) failed and led to the fixes recorded in the [report](../../architecture/investigations/2026-10-26-wp-m1-02-storage-and-execution.md#findings-from-the-hosted-runs); this record is the passing run on the commit above.
